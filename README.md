# OTP Vault

서버 없이 **내 브라우저 안에서** OTP(TOTP·HOTP) 인증번호를 암호화해 보관하고 생성하는 확장프로그램입니다.
Google Authenticator, Microsoft Authenticator 같은 앱과 **같은 표준 방식(RFC 6238 / RFC 4226)**으로 코드를 만들기 때문에, 표준 OTP를 쓰는 서비스에서 그대로 사용할 수 있습니다.

- 버전: **0.5.0 (프로토타입)** · 라이선스: [MIT](#라이선스)
- 대상: **Windows PC의 Chrome · Edge · Firefox** (Safari는 macOS 전용이라 후속, 모바일은 개발 보류)
- 한 줄 요약: 모든 데이터는 이 브라우저에만 암호화되어 저장되고, 인터넷으로 아무것도 보내지 않습니다.

## 설치 (개발자 모드, 스토어 등록 전)
zip 압축을 먼저 풀어 두세요. 설치용 폴더는 `dist` 안에 이미 만들어져 있습니다.

| 브라우저 | 방법 |
|---|---|
| Chrome | 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → `dist/chrome-edge` 폴더 선택 |
| Edge | 주소창에 `edge://extensions` → 왼쪽 **개발자 모드** 켜기 → **압축 풀린 항목 로드** → `dist/chrome-edge` 폴더 선택 |
| Firefox | 주소창에 `about:debugging#/runtime/this-firefox` → **임시 부가 기능 로드** → `dist/firefox/manifest.json` 선택 (Firefox를 끄면 사라집니다. 영구 설치는 Mozilla 서명이 필요합니다) |

- 폴더를 고를 때는 안에 `manifest.json`이 바로 보이는 폴더(`dist/chrome-edge`)를 고르세요. zip 파일을 그대로 끌어다 놓으면 설치되지 않습니다.
- 설치 후 툴바의 퍼즐 아이콘에서 OTP Vault를 고정하고, 처음 열면 마스터 비밀번호(10자 이상)를 만듭니다.
- 지원 브라우저 버전: Firefox는 140 이상(manifest에 지정). Chrome·Edge는 최신 버전을 권장합니다. 오래된 버전에서는 `storage.session`을 쓰는 "잠금 해제 유지"가 동작하지 않을 수 있습니다.

## 업데이트 (이미 설치해서 쓰고 있는 경우)
1. **먼저 설정·백업에서 백업 파일을 만들어 두세요.**
2. 새 zip을 풀어서 기존과 같은 위치의 `dist` 폴더를 덮어씁니다. (폴더 위치가 바뀌면 새 확장으로 인식되어 데이터가 따로 생깁니다)
3. 확장프로그램 관리 화면(`chrome://extensions`, `edge://extensions`)에서 OTP Vault의 **새로고침(↻)** 버튼을 누르면 저장된 계정이 유지됩니다.
4. **"제거"는 누르지 마세요.** 제거하면 보관소가 삭제되고, 백업 파일로만 복원할 수 있습니다.
- Firefox는 임시 설치라 재시작할 때마다 다시 불러와야 하며, 데이터가 유지되는지 확실하지 않으니 항상 백업을 먼저 해 두세요.

## 기능 전체

### 계정 등록
- **화면에서 드래그로 QR 가져오기 (팝업, 추천)**: QR이 보이는 웹페이지에서 팝업의 **"화면에서 QR 영역 드래그하기"**를 누르면 팝업이 닫히고 페이지 위에 선택 화면이 올라옵니다. QR 부분을 마우스로 드래그해 지정하면 그 영역만 캡처해 해독하고, 새 탭(관리 페이지)에서 **서비스·계정 이름을 보여 주며 "추가"를 눌러야** 등록됩니다. 영역이 너무 작거나 QR을 못 찾으면 안내가 뜨고 바로 다시 드래그할 수 있습니다(Esc: 취소). 모니터 배율·브라우저 확대/축소를 반영하고, QR에 딱 붙게 선택해도 읽히도록 여백을 보정하며, Google 내보내기 QR도 같은 방식으로 가져옵니다.
- **QR 이미지 파일**(PNG/JPG) 가져오기, 또는 화면 캡처(Win+Shift+S) 후 **Ctrl+V 붙여넣기**. 이미지는 이 PC 안에서만 처리되며 어디에도 전송·저장되지 않습니다. 브라우저에 내장 `BarcodeDetector`가 있으면 그것을 먼저 쓰고, 없으면 직접 구현한 QR 디코더를 씁니다.
- **`otpauth://` 주소** 붙여넣기 (`totp`·`hotp`, 서비스 이름·알고리즘·자릿수·주기·카운터 인식)
- **비밀키 직접 입력** (4글자씩 끊긴 공백·소문자·`=` 패딩은 자동 정리, 잘못된 문자는 오류 처리, 16자 미만은 거부)
- **Google Authenticator "계정 내보내기"** QR/주소(`otpauth-migration://`)를 가져오면 여러 계정이 한 번에 들어옵니다. QR이 여러 장이면 장마다 반복하세요. 중복·미지원 항목(MD5 등)은 건너뛰고 개수를 알려 줍니다.
- 같은 **서비스 이름 + 계정 이름**(대소문자 무시)은 중복으로 보고 등록을 막습니다.
- 팝업은 파일 선택 시 닫히는 브라우저 특성 때문에, 파일을 고르는 작업은 **관리 페이지**(팝업의 "관리" 버튼)에서 하는 것을 권장합니다.

### OTP 방식
- **TOTP**(시간 기반): SHA-1 / SHA-256 / SHA-512, 6~10자리, 주기 1~3600초(기본 6자리·30초). 코드는 매번 현재 시간으로 계산합니다.
- **HOTP**(횟수 기반): 현재 카운터의 코드를 보여 주고 **"다음 번호"** 버튼으로 카운터를 올립니다. 서비스와 어긋나면 수정 화면에서 카운터를 맞춥니다.
- 지원하지 않는 것: Steam Guard, 은행 전용 OTP·보안카드, 푸시 승인(예: Microsoft Authenticator의 알림 승인), 패스키(FIDO) — 표준 OTP가 아니기 때문입니다.

### 목록 화면
- 인증 코드(클릭하면 복사 / "복사" 버튼), TOTP는 남은 시간 막대·숫자, HOTP는 카운터 표시
- 검색, 즐겨찾기(★, 항상 맨 위), 서비스 이니셜 아이콘(서비스 이름마다 색 고정), 수정, 삭제("삭제"를 두 번 눌러 확인 — 브라우저 대화상자를 쓰지 않음)
- 정렬: 이름순 / 사용자 지정(관리 페이지에서 ↑↓로 이동)
- 계정 수정: 서비스 이름·계정 이름·알고리즘·자릿수·주기(HOTP는 카운터), 비밀키는 비워 두면 유지
- 클립보드 복사는 사용자가 누를 때만 일어나며, 자동으로 지워 주지는 않습니다.

### 잠금과 비밀번호
- 마스터 비밀번호(10자 이상)로 보관소를 만들고 잠금 해제
- **직접 잠금**, **자동 잠금**(조작이 없으면 1·5·15·30분 뒤), 기본적으로 팝업을 닫으면 다음에 다시 비밀번호 입력
- **잠금 해제 유지(선택, 기본 꺼짐)**: "브라우저를 끌 때까지 / 1시간 / 8시간" 동안 팝업을 열 때 비밀번호를 다시 묻지 않습니다. 암호 키는 디스크가 아닌 브라우저 메모리(`storage.session`)에만 있고, 잠금 버튼·자동 잠금·브라우저 종료·기간 만료 때 사라지고, 이 설정을 바꾸면 즉시 지워지며, 마스터 비밀번호를 바꾸면 새 키로 교체됩니다. 설정을 바꾼 뒤 비밀번호를 한 번 입력해 잠금을 풀면 적용됩니다.
- **마스터 비밀번호 변경**(현재 비밀번호 확인 → 새 salt로 전체 재암호화)
- **비밀번호를 잊었을 때**: 복구할 방법은 없습니다. 보관소를 영구 삭제("삭제"를 직접 입력해야 함)한 뒤 백업 파일로 복원할 수 있습니다.
- 이전 버전(PBKDF2) 보관소는 비밀번호로 한 번 열면 자동으로 Argon2id로 업그레이드됩니다.

### 백업과 복원 (관리 페이지의 "설정·백업")
- **암호화 백업 내보내기**: 현재 마스터 비밀번호로 암호화된 JSON 파일 (파일명 `otp-vault-backup-날짜.json`)
- **백업 가져오기**: 기존 계정에 합칩니다. 같은 서비스·계정 이름이 있을 때 "건너뛰기 / 덮어쓰기"를 고릅니다. 비밀번호가 틀리거나 파일이 손상되면 아무것도 가져오지 않습니다.
- **빈 보관소에서 복원**: 처음 화면에서 백업 파일 + 백업 비밀번호로 복원하면, 그 비밀번호가 새 보관소의 마스터 비밀번호가 됩니다.
- **브라우저 간 이동**: 백업 형식이 모든 브라우저에서 같아서 Chrome → Edge → Firefox 사이를 파일로 옮길 수 있습니다.
- **결과 알림**: 백업 가져오기·내보내기, 빈 보관소 복원, 마스터 비밀번호 변경의 결과를 **버튼 바로 아래 결과 칸**과 **화면 가운데 알림 창**(초록 = 성공, 빨강 = 실패, "확인"을 눌러 닫음)으로 알려 줍니다. 계산에 1~2초 걸리는 동안에는 "확인하는 중입니다"가 표시됩니다.
- **백업 알림**: 백업 파일을 만든 적이 없거나, 마지막 백업 이후 바뀐 내용이 3·7·30일 넘게 백업되지 않으면 목록 위에 안내가 뜹니다("나중에"로 이번 화면에서만 숨김, 설정에서 끌 수 있음).

### 자가 진단 (설정·백업 맨 아래)
**진단 실행**을 누르면 지금 쓰는 브라우저에서 핵심 기능이 실제로 동작하는지 확인하고 `[통과] / [실패] / [참고]`로 보여 줍니다. **결과 복사**로 내용을 복사해 문제 보고에 쓸 수 있습니다. 계정 데이터는 건드리지 않습니다.
결과는 **통과 = 초록, 실패 = 빨강, 참고 = 노랑**으로 표시하고 맨 위에 전체 요약("모두 정상")이 나옵니다.

## 데이터와 개인정보
**이 프로그램은 어떤 데이터도 수집하거나 전송하지 않습니다.** 서버가 없고, 분석 도구·광고·원격 코드·외부 글꼴이 없으며, 코드에 네트워크 요청(`fetch` 등)이 없습니다. 요청하는 브라우저 권한은 `storage`, `activeTab`, `scripting` 세 가지이며 이유는 아래 표에 적었습니다.

| 저장 위치 | 내용 | 형태 |
|---|---|---|
| `storage.local` → `vault` | 계정 목록(서비스·계정 이름, 비밀키, 방식, 즐겨찾기, 카운터 등) | **암호화**(AES-256-GCM) |
| `storage.local` → `settings` | 자동 잠금·정렬·잠금 해제 유지·백업 알림 설정, 마지막 백업 시각, 백업 이후 처음 변경된 시각 | 평문(비밀 아님) |
| `storage.session` → `unlock` | (잠금 해제 유지를 켠 경우만) 암호 키 | 브라우저 메모리에만 존재, 브라우저를 끄면 삭제 |

- 마스터 비밀번호 자체는 어디에도 저장하지 않습니다.
- 확장프로그램을 제거하거나 브라우저 프로필을 삭제하면 위 데이터가 모두 사라집니다. 백업 파일은 사용자가 직접 만들어 보관하는 파일이며, 이 프로그램이 읽거나 전송하지 않습니다.
- Chrome Sync·Firefox Sync 등 브라우저 계정 동기화(`storage.sync`)는 사용하지 않습니다.

**요청하는 권한**
| 권한 | 왜 필요한가 | 범위 |
|---|---|---|
| `storage` | 암호화된 보관소·설정 저장 | 이 확장프로그램 전용 저장 공간 |
| `activeTab` | "화면에서 QR 가져오기"를 눌렀을 때 **그 탭의 화면을 한 번 캡처** | 사용자가 확장프로그램을 눌러 연 탭에만, 잠깐 동안만. 모든 사이트 접근 권한(`<all_urls>` 등)은 요청하지 않음 |
| `scripting` | 같은 순간에 그 탭에 드래그 선택 화면(작은 스크립트)을 올림 | 버튼을 누른 탭에만 |

**화면 캡처는 이렇게 다룹니다**
- 버튼을 누르고 영역을 드래그했을 때만 캡처합니다. 항상 감시하거나 자동으로 캡처하지 않습니다.
- 캡처한 화면은 메모리에서 QR 해독에만 쓰고 곧 버립니다. 파일로 저장하거나 어디로도 보내지 않으며, 드래그하지 않은 부분은 처리하지 않습니다.
- 해독된 `otpauth://` 주소(비밀키 포함)는 디스크가 아닌 브라우저 메모리(`storage.session`)에 최대 10분만 두었다가, 관리 페이지에서 "추가"나 "취소"를 누르면 바로 지웁니다. 암호 키는 백그라운드에 없으며, 계정은 마스터 비밀번호로 잠금을 푼 관리 페이지에서만 추가됩니다.
- 페이지에 올라가는 선택 화면 스크립트는 페이지 내용을 읽지 않고(DOM 조회·쿠키 접근 없음) 드래그한 좌표만 확장프로그램으로 보냅니다.

## 보안 설계
- **키 파생**: 마스터 비밀번호 → **Argon2id**(메모리 19 MiB, 2회, 병렬 1, 16바이트 무작위 salt; OWASP 권고 최소 구성) → 256비트 키
- **암호화**: AES-256-GCM, 저장할 때마다 새 12바이트 nonce. 형식·버전·KDF 매개변수 전체를 AAD로 묶어 헤더를 바꾸면 복호화가 실패합니다.
- Argon2id와 BLAKE2b는 외부 라이브러리 없이 **직접 구현**했고, RFC 9106 공식 시험 벡터와 독립 구현(Python `cryptography`)의 결과와 일치함을 확인했습니다. 순수 JavaScript라 계산에 PC에서 약 1~2초 걸리며 그동안 화면이 잠시 멈출 수 있습니다.
- 변조된 파일로 과도한 메모리·시간을 쓰지 못하도록 KDF 매개변수 상한을 검사합니다(Argon2id: 메모리 ≤ 64 MiB, 반복 ≤ 10, 병렬 = 1).
- 화면에 표시하는 모든 사용자 데이터는 `textContent`로만 넣습니다(`innerHTML` 미사용). 원격 코드·`eval`·인라인 스크립트가 없고, 확장 페이지 CSP는 `script-src 'self'; object-src 'self'`입니다.
- 검색 가능한 평문 비밀키·비밀번호가 저장소·파일·로그에 남지 않는지 자동 시험으로 확인합니다.

## 백업 파일 형식
JSON 한 개 파일이며 내용은 암호화되어 있습니다.
```json
{
  "format": "otp-vault-backup",
  "formatVersion": 2,
  "kdf": { "name": "Argon2id", "version": 19, "memoryKiB": 19456, "iterations": 2, "parallelism": 1, "salt": "<base64 16바이트>" },
  "cipher": { "name": "AES-256-GCM", "nonce": "<base64 12바이트>", "ciphertext": "<base64>" }
}
```
복호화하면 `{ "accounts": [ { id, type, issuer, label, secret, algorithm, digits, period, counter(HOTP만), favorite, createdAt } ] }`가 나옵니다. 형식 버전 1(PBKDF2, 0.1~0.3)도 읽을 수 있고, 새로 만드는 파일은 형식 버전 2입니다.

## 알려진 한계
- **실제 브라우저에서 모든 기능을 확인하지는 못했습니다.** ([검증 상태](#검증-상태) 참고)
- 0.4.0 이후에 만든 백업 파일(형식 2)은 0.3.0 이하 버전에서 열 수 없습니다(반대 방향은 가능).
- QR 디코더는 직접 만든 시험 이미지로만 검증했습니다. 1픽셀 배율 이미지, 25~45° 정도 기운 사진, 잡음이 심한 사진은 읽지 못할 수 있습니다. 그럴 때는 QR 부분만 크게 잘라 다시 시도하거나 비밀키를 직접 입력하세요.
- Google 내보내기 형식은 공식 문서가 없어 공개된 구조를 바탕으로 구현했고, 실제 Authenticator가 만든 QR로는 아직 확인하지 못했습니다.
- Argon2id는 순수 JavaScript라 WASM 구현보다 느립니다(특히 Firefox).
- "잠금 해제 유지" 중에는 잠금이 풀려 있는 동안 이 PC를 쓰는 사람이 OTP를 볼 수 있습니다. 공용 PC에서는 끄고, 자리를 비울 때는 Win+L로 PC를 잠그세요.
- PC의 악성코드·키로거, 브라우저 자체 침해, 잠금 해제 중의 메모리 접근, 클립보드 감시는 막을 수 없습니다. JavaScript 특성상 메모리 속 키·비밀키를 확실히 지우는 것도 보장하지 못합니다.
- OTP는 가짜 사이트에 번호를 입력하게 만드는 실시간 피싱을 완전히 막지 못합니다. 서비스가 지원하면 패스키 같은 피싱 저항 인증도 함께 쓰세요.
- **화면 드래그 QR의 제한**: 브라우저 내부 페이지(`chrome://`, `edge://`, `about:`)·확장/스토어 페이지·일부 보호된 페이지에서는 막혀 있어 쓸 수 없습니다(이때는 화면 캡처 후 Ctrl+V나 이미지 파일로 가져오세요). 현재 화면에 보이는 부분만 캡처하므로 QR이 창에 가려졌거나 너무 작으면 확대한 뒤 시도하세요. 계정은 새 탭의 관리 페이지에서 마스터 비밀번호로 잠금을 푼 뒤 추가됩니다(잠금 해제 유지를 켜 두면 다시 묻지 않음).
- 이름순 정렬은 브라우저의 한글/영문 정렬 규칙을 따르므로 브라우저마다 순서가 다를 수 있습니다.
- 마스터 비밀번호를 잊으면 복구할 수 없습니다. 복구 코드·클라우드 백업·계정 동기화 기능은 의도적으로 넣지 않았습니다.
- PC 시계가 틀리면 TOTP 코드가 맞지 않습니다. Windows 시간 자동 동기화를 켜 두세요.
- Safari(macOS), 모바일, 자동 입력, 스토어 등록은 아직 없습니다.
